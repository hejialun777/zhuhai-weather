# 珠海市天气 · Zhuhai Weather

一个查珠海实时天气与未来预报的单文件网页。纯 HTML / CSS / JavaScript，零第三方依赖、零构建、零 API Key，双击就能在浏览器里跑。

## 解决的问题

查国内天气要装 App，用网页版往往被广告和弹窗包围，而且默认只给「珠海市」一个笼统的数字——但珠海是组团式城市，香洲、斗门、金湾、横琴之间海陆位置差别很大，同一时刻的天气经常不一样。

这个项目做两件事：**免安装免注册**，一个 HTML 文件双击打开就有数据；**精确到区**，五个区按各自经纬度分别取数。

## 运行

双击 `index.html`，用 Chrome / Edge / Firefox 打开即可。不需要安装任何东西，不需要 Node.js，**不需要本地服务器**。

## 当前功能

- **实时实况**：当前气温、天气状况、今日最高/最低、日出日落、紫外线
- **指标格（7 项）**：体感温度、相对湿度、风速风向、降水概率与雨量、气压、紫外线、空气质量 AQI + PM2.5
- **未来 24 小时**：上为气温 + 体感温度双曲线，下为降水概率柱状图，共用一条时间轴
- **生活指数（6 项）**：穿衣、洗车、晾晒、运动、感冒、中暑，由实测数据推算
- **未来 7 天**：每日低温→高温区间条，七天共用同一温度刻度
- **数据表格**：一键展开全部原始数值
- **区域切换**：香洲区 / 金湾区 / 斗门区 / 横琴合作区 / 高新区
- **自动定位**：打开时按浏览器定位选最近的区，超出 60 公里不硬套
- **深浅色主题**：跟随系统 / 浅色 / 深色三态

## 数据源

[Open-Meteo](https://open-meteo.com/) 开放接口：免费、无需注册、无需 API Key，返回 `access-control-allow-origin: *`，所以用 `file://` 直接打开也能正常取数。

- 预报数据：`api.open-meteo.com/v1/forecast`
- 空气质量：`air-quality-api.open-meteo.com/v1/air-quality`

## 说明

预报为数值模式结果，仅供参考。天气图标使用 Emoji，在 Windows 上由 Segoe UI Emoji 渲染。
