# 珠海市天气 · Zhuhai Weather

一个查珠海实时天气与未来预报的单文件网页。纯 HTML / CSS / JavaScript，**零第三方依赖、零构建、零 API Key**，双击就能在浏览器里跑。

---

## 解决的问题

查国内天气要装 App，用网页版往往被广告、弹窗、登录墙包围，而且默认定位到「珠海市」时给的是全市一个笼统的数字——但珠海是组团式城市，香洲、斗门、金湾、横琴之间海陆位置差别很大，同一个时刻的天气经常不一样，出门带不带伞的结论可能正好相反。

这个项目做三件事：

1. **免安装、免注册、免广告**——一个 HTML 文件，双击打开就有数据。
2. **精确到区**——五个区（香洲 / 金湾 / 斗门 / 横琴合作区 / 高新区）按各自经纬度分别取数，不是全市一个值。
3. **直接给结论**——不只报数字，还给出「要不要带伞、适不适合洗车、该穿什么」这类可执行的判断。

数据源用 [Open-Meteo](https://open-meteo.com/) 开放接口：免费、无需注册、无需 API Key，返回 `access-control-allow-origin: *`，所以用 `file://` 直接打开也能正常取数。

## 主要功能

| 模块 | 内容 |
|---|---|
| **实时实况** | 当前气温、天气状况、今日最高/最低、日出日落时间、紫外线最高值 |
| **指标格（7 项）** | 体感温度、相对湿度、风速与 16 方位中文风向、今日降水概率与雨量、气压、紫外线指数、空气质量 AQI + PM2.5 |
| **未来 24 小时** | 上：气温 + 体感温度双曲线；下：降水概率柱状图。两个面板共用一条时间轴 |
| **生活指数（6 项）** | 穿衣、洗车、晾晒、运动、感冒、中暑，由实测气温 / 湿度 / 风速 / 降水 / 紫外线 / AQI 推算 |
| **未来 7 天** | 每日低温→高温区间条，七天共用同一温度刻度；今天额外标出当前温度点 |
| **数据表格** | 一键展开全部原始数值，供读屏软件、复制粘贴、逐项核对 |
| **区域切换** | 香洲区 / 金湾区 / 斗门区 / 横琴合作区 / 高新区 |
| **自动定位** | 打开时按浏览器定位选最近的区，超出 60 公里不硬套 |

另外还有：深浅色主题（跟随系统 / 浅色 / 深色三态，记住选择）、每 10 分钟自动刷新、窄屏自适应。

## 运行 / 使用说明

### 运行

**双击 `index.html`**，用 Chrome / Edge / Firefox 打开即可。

不需要安装任何东西，不需要 Node.js，**不需要本地服务器**。数据靠浏览器直接请求 Open-Meteo，接口允许跨域，`file://` 协议下也能取数。

如果因为网络原因打不开数据（页面提示「获取天气数据失败」），可以起一个本地服务器再试：

```bash
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000/index.html
```

### 使用

| 操作 | 效果 |
|---|---|
| 点顶部**区域名** | 切换城市 |
| 点**📍 定位** | 按当前位置重新选区 |
| 点**刷新** | 立即重新取数 |
| 点**主题按钮** | 在「跟随系统 → 浅色 → 深色」之间循环 |
| **悬停 24 小时图** | 十字准星贯穿两个面板，一次给出气温、体感、降水概率、降水量 |
| **悬停 7 天图** | 显示当天天气、降水、风速、紫外线、日出日落 |
| 点**显示数据表格** | 展开全部数值 |

## 自主设计的实用点

### 1. 降水柱不跟温度共用一根 Y 轴

气温是 25~36°C，降水概率是 0~100%，两者量纲不同。把它们叠在同一根 Y 轴上是数据可视化里最常见的错误——读者会不自觉地去比较两条柱子/曲线的相对高度，而那个比较是没有意义的。

这里做成**上下两个面板**：各自独立刻度，只共享时间轴。十字准星贯穿两层，所以对照着看很方便，但不会误导。

### 2. 全程无雨时不画空面板

未来 24 小时降水概率都低于 5% 时，照常画出来就是一条 90 像素高的空白带——看着像页面坏了，而不是像「没有雨」。

这种情况改成一行文字说明「未来 24 小时无明显降水（最高 0%）」，图表高度从 310px 收到 242px，把空间还给温度曲线。珠海旱季这种日子很多，这个分支经常走到。

### 3. 定位不阻塞首屏

浏览器定位要弹权限框，用户可能想几秒才点。如果等定位结果再取数，这段时间用户对着的是白屏。

这里的做法是：**先按默认的香洲区把整页渲染出来**，定位有结果了再判断要不要切区重取。只认 60 公里内的位置，超出就保持默认区并说明「当前位置不在珠海范围内」，而不是硬套一个几百公里外的区。另外，用户一旦手动点过区域，自动定位就不再覆盖他的选择。

### 4. 坐标轴刻度只在数据范围内取整

最初的实现是把坐标轴定义域向外扩到刻度步长的整数倍。结果 26~36°C 的数据被撑到 20~40°C，图里有一半是空的，曲线全挤在上半部分。

改成**只在数据范围内取 1/2/5/10 的整数刻度**，并且当网格线少于 4 根时自动加密一档。现在 26~36°C 的数据会得到 26/28/30/32/34/36 六根线，数据占满绘图区，刻度还都是整数。

### 5. 配色跑过色觉障碍校验

曲线用的三个颜色（气温蓝 `#2a78d6` / 体感橙 `#eb6834` / 降水青 `#1baf7a`）在浅色和深色两套主题下都做了**红绿色盲、蓝黄色盲的分离度校验**，全部通过。

另外，曲线末端、峰值、每日高低温都有**直接的数字标注**，不靠颜色单独承载信息。浅色模式下青色对背景的对比度是 2.74:1，低于 3:1 的无障碍标准，所以额外配了图例、面板名和数据表格三条兜底路径。

### 6. 中文语境下的细节

- 风向转成 16 方位中文（如「东东南风」），不是裸的角度数字
- 28 个 WMO 天气代码全部映射为中文描述 + 区分昼夜的图标
- 生活指数的判断阈值按国内体感习惯定，不是直译国外标准

- 生活指数由气温、湿度、风速、降水、紫外线推算，**不是官方发布**。
- 天气图标使用 Emoji，在 Windows 上由 Segoe UI Emoji 渲染；不同系统下样式略有差异。
